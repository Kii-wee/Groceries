# Groceries
This is a grocery list manager I made as a project for one of my courses. This grocery list manager allows the user to manage a personal list of food items with real-time updates through an interactive menu.

## THE FEATURES
1. Add Items: Insert new items onto your grocery list.
2. Mark as bought: Mark an item with "x" when you have it in your cart without fully removing the item from the list.
3. Remove item: Delete items you do not need.
4. Show list: Gives an overview on what items you currently have in your list and what items are marked "x" as bought.
5. Quit: Close the program.

## HOW TO RUN
1. Open 'Grocery List.py' in PyCharm or any Python 3 environment.
2. Run the script in the terminal.
3. Follow the on screen menu prompts to manage your list!
